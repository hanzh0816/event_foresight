# 后续探索目标

记录日期：2026-11-12。以下三项由用户确认为再下一步的研究目标，当前只记录，不实现，也未启动实验。

当前实现范围分为两个独立分支：

- `codex/event-predictor-finetune`：冻结已训练的 full_joint Event Encoder，只微调 Predictor，以真实未来 RGB 特征监督。
- `codex/event-200ms-joint`：200ms recent_fine 输入，仅训练 Encoder 的 current + future joint 目标，Predictor 冻结。

两条路线均保持 Event-only 历史输入、无动作条件、训练时可使用配对 RGB Teacher；Detector 不参与这两个表示训练目标。真实训练完成情况与结果另行登记。

## 1. Encoder 的监督分配

**目标：** 检验全局平均特征损失是否弱化了局部目标结构，尤其是行人和小目标。现有类别差异只是探索依据，尚未定位原因。

**候选方法：** 在保留全局对齐的基础上增加局部 crop、Teacher 显著区域或 token 关系蒸馏；分别考察局部结构与跨区域语义关系。仅按事件密度加权可能忽略低活动区域，需要保留相应对照。若使用 GT 框或类别分配权重，单列为标签辅助方案。

**验证：** 相同编码器、输入与训练预算下比较当前/未来任务；报告逐类 AP、目标尺寸与事件密度切片及稠密表示质量，不能以全局特征误差单独判断。

## 2. 多时域预测

**目标：** 从目前的名义未来 50ms 扩展到 100ms、200ms 等时域，检验表示能否持续支持未知未来预测。

**候选方法：** 先诊断已有一步模型的递归 rollout，再比较直接多时域预测与多步 rollout 训练。所有预测共享同一个历史截止时刻；后续真实 RGB/Event 只能作为训练或评价目标。

**验证：** 每个时域分别比较状态保持、简单外推与模型预测，并使用匹配的读出协议。记录 rollout 误差累积；当前一步模型递归结果不等同于已完成多时域训练。

## 3. 保留事件特有的动态信息

**目标：** 检验完全对齐 RGB PCA 表示是否限制了对预测有用的事件动态信息，而非预设存在这种瓶颈。

**候选方法：** 在 RGB 语义蒸馏之外加入轻量未来事件活动/统计预测目标；或保留事件原生隐状态，只通过单独的语义读出映射到 RGB 空间。先验证最小辅助目标，再考虑结构扩展。

**验证：** 比较有无辅助目标时的未来检测、较长时域预测与跨任务表现。未来事件只作监督；降低事件重建误差本身不构成 WM 能力提升的证据。

## 本轮不实施的内容

以上三项不加入当前两个实验分支的训练损失、数据接口或模型结构；Encoder + Predictor 联合更新也不属于当前实现范围。先完成两条已授权训练路线的实验，再据结果确定后续方案与预算。
